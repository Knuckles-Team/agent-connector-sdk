# SCION-FINANCE-SOURCES requirements

| ID | Requirement | Verification |
|---|---|---|
| `SCION-FINANCE-SOURCES-R001` | **Market-data adapters: exchange history fix, CoinMarketCap, FRED/ALFRED.** Market-data source adapters correct historical price retrieval for the exchange market-data connector, add CoinMarketCap market data, and add Federal Reserve FRED/ALFRED series with a central-bank announcement calendar, each preserving data vintage and announcement time per the shared adapter contract. | Offline conformance tests using recorded or synthetic responses for each adapter verifying corrected history retrieval and vintage and announcement-time fields. |
| `SCION-FINANCE-SOURCES-R001.1` | **Finite FRED values.** FRED normalization and direct macro-observation construction reject non-finite values instead of emitting invalid financial observations. | `tests/test_finance_fred_series.py::test_nonfinite_values_are_rejected` covers NaN, infinity, and overflow through both paths. |
| `SCION-FINANCE-SOURCES-R001.2` | **Cross-provider conformance.** Verify exchange history, CoinMarketCap, FRED/ALFRED vintage and central-bank announcement times through their real source adapters under the shared contract. | `tests/test_finance_market_source.py` exercises each source kind through MCP and the sink, including distinct FRED vintages and refusal cases. The owner connectors have separate served-source and graph evidence. |
| `SCION-FINANCE-SOURCES-R001.3` | **Refuse same-page calendar identity collisions.** If distinct announcement times map to one legacy event identity, refuse the page rather than return conflicting records. Equivalent timestamps for the same instant do not conflict. Existing IDs stay unchanged. | `tests/test_finance_central_bank_calendar.py` covers collision refusal and equivalent offsets. |
| `SCION-FINANCE-SOURCES-R001.4` | **FRED page shape.** FRED normalization rejects a missing or malformed observations array while accepting an explicit empty array. | `tests/test_finance_fred_series.py::test_observation_page_requires_an_array` covers invalid and empty pages. |
| `SCION-FINANCE-SOURCES-R001.5` | **Canonical FRED identity dates.** Observation and vintage dates use canonical calendar-date text. Alternate or malformed forms refuse before the event ID is built. | `tests/test_finance_fred_series.py` covers refusal and stable IDs. |
| `SCION-FINANCE-SOURCES-R001.6` | **Unique FRED page identities.** Refuse a page that repeats an observation period and vintage identity. Distinct vintages remain distinct records. | `tests/test_finance_fred_series.py` covers repeated IDs with equal and differing values. |
| `SCION-FINANCE-SOURCES-R002` | **Alpaca stocks adapter: history, quotes, fundamentals, calendars.** The Alpaca stocks source adapter supports historical bars, quotes, and streaming data with bounded pagination and explicit adjusted-versus-unadjusted and regular/pre/post-market handling, plus profile and fundamentals data, original generated stock illustrations, news, and an earnings and dividend calendar. | Offline conformance tests against recorded Alpaca fixtures covering pagination, adjustment mode, extended-hours flags, generated illustrations, and each additional data type. |
| `SCION-FINANCE-SOURCES-R002.1` | **Complete Alpaca source coverage.** The source adapter supports bounded history, quotes, streaming and fundamentals. It also provides original generated stock illustrations, news, earnings and dividend calendars. Generated illustrations are identified as non-official and do not claim to depict a company logo. It handles regular and extended hours explicitly. | Offline source-adapter conformance fixtures cover all required data types, pagination, session handling, adjustment modes and generated image provenance. |
| `SCION-FINANCE-SOURCES-R002.2` | **Finite market records.** Bars, quotes and corporate actions reject non-finite numeric values. | `tests/test_finance_records.py::test_market_records_reject_nonfinite_values` covers each numeric field. |
| `SCION-FINANCE-SOURCES-R002.3` | **Alpaca page shape.** Bar normalization requires a valid bars array, the requested symbol and an explicit pagination token. It rejects malformed pages rather than assuming completion. | `tests/test_finance_alpaca_stocks.py::test_malformed_page_is_rejected` and `test_explicit_empty_page_is_valid` cover refusal and empty data. |
| `SCION-FINANCE-SOURCES-R003` | **FX, commodities, and real-estate adapters with roll and staleness rules.** FX source adapters identify base and quote currency and rate direction. Gold and commodities adapters distinguish spot price from a specific futures contract, its expiry, and an explicit roll rule. Real-estate adapters return a dated, potentially stale valuation rather than a live market quote. | Offline conformance tests per asset class asserting correct base/quote identity, spot-versus-futures roll handling, and valuation staleness reporting. |
| `SCION-FINANCE-SOURCES-R003.1` | **Multi-asset source adapters.** Provide and verify FX, commodity and real-estate source adapters. Preserve rate direction, futures roll rules and dated valuation staleness. | `tests/test_finance_multi_asset_source.py` exercises canonical MCP source records through the adapter and sink, including refusal before commit. Provider-specific APIs remain outside this evidence. |
| `SCION-FINANCE-SOURCES-R003.2` | **Finite multi-asset prices.** FX rates and commodity prices refuse non-finite values; FX inversion refuses overflow instead of returning a non-finite rate. | `tests/test_finance_records.py` covers invalid values and inversion overflow. |
| `SCION-FINANCE-SOURCES-R003.3` | **Canonical FX currency identity.** FX base and quote codes use three ASCII letters in uppercase. The model refuses a pair with identical codes. | `tests/test_finance_records.py` covers normalization, distinctness and malformed codes. |
| `SCION-FINANCE-SOURCES-R003.4` | **Provider-specific multi-asset source coverage.** Read FX, spot and futures prices, and real-estate valuations through actual provider integrations. Emerald Exchange `tests/test_multi_asset_sources.py` exercises provider transport fixtures, and `tests/test_multi_asset_sources_graph.py::test_provider_records_through_sdk_and_graph` exercises the served pack, SDK adapter and real graph replay. |

| `SCION-FINANCE-SOURCES-R004.3` | **Reject duplicate CSV headers.** Preview and import refuse repeated header names before parsing activity rows. | `tests/test_finance_csv_import.py::test_duplicate_headers_are_rejected` covers mapped and unmapped duplicates. |

| `SCION-FINANCE-SOURCES-R005` | **Macro and liquidity panels: FRED series, ETF flows, sentiment, on-chain.** Macro and liquidity source adapters provide Federal Reserve FRED series with preserved vintage, a versioned liquidity composite and heat-strip panel, ETF fund-flow data, sentiment data, and on-chain position data, each tagged with its source and observation time. | Offline conformance tests against recorded or synthetic fixtures for each panel type asserting vintage preservation and correct source provenance tagging. |

| `SCION-FINANCE-SOURCES-R901` | **Probabilistic series forecast provider contract.** Stage: connector contract. Caller: the conformance kit that every forecast connector passes, and `ARBORA-DATA-MARKET` operation ARBORA-DATA-MARKET-R008 through the SDK adapter. Code: `ForecastRequest { series_ids: list, model_revision, temperature, top_p, sample_count, seed }` and `ForecastResponse { per_series: list keyed by series id, model_revision, seed }` in `scion_sdk/finance/forecast.py`. Rule: `temperature` is in (0, 2]. `top_p` is in (0, 1]. `sample_count` is in [1, 1024]. `seed` is a required unsigned 64-bit integer. Results come back in request order, one entry per series id. Evidence: the response echoes the controls, seed and model revision. Writes: none. Depends on: EG-FINANCE-PRIMITIVES-R902 as the evidence consumer. | Test: `tests/test_forecast_provider_conformance.py::test_controls_order_and_refusals` (conformance kit run) asserts bounds, order and each refusal against a loopback provider. |
