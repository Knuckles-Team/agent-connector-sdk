# SDK-OBSERVABILITY-FEEDS requirements

| ID | Requirement | Verification |
|---|---|---|
| `SDK-OBSERVABILITY-FEEDS-R001` | **RUM, security-audit, and CI/CD events join the durable source pipeline.** RUM, security-audit, and CI/CD events enter the same durable source pipeline as other systems of record, carrying a standard event envelope with stable identity, event, observed, and ingest times, actor and target references, and schema version; the adapter contract does not itself interpret an event as a verified incident, vulnerability, release, or user outcome. | Conformance tests using synthetic RUM, audit, and CI/CD event fixtures asserting correct envelope fields, idempotent event identity, and schema-drift quarantine behavior. |
| `SDK-OBSERVABILITY-FEEDS-R001.1` | **Rejected page identity isolation.** A page that fails validation cannot add event identities to the adapter tracker. A later retry of its valid events must emit them. This guard does not prove durable acceptance or restart recovery. | `tests/test_event_feeds.py::test_rejected_page_does_not_poison_event_identity` |
| `SDK-OBSERVABILITY-FEEDS-R001.2` | **Event identity receipt boundary.** Promote staged identities only after the worker validates the matching sink receipt. A failed or uncertain submission must not discard records on retry. | `tests/test_event_feeds.py::test_event_identity_waits_for_worker_acceptance` |
| `SDK-OBSERVABILITY-FEEDS-R001.3` | **Durable event receipt proof.** A running graph accepts the page and returns the matching durable receipt. Restart the worker and prove a retry neither loses nor duplicates an event. | OF-06 records graph readback and restart evidence. |
| `SDK-OBSERVABILITY-FEEDS-R001.4` | **Event adapter registration.** The sync command discovers and activates a certified event-feed adapter from a declared feed kind. A served connector run reaches the adapter through the standard registry. | Exercise connector-sync with a registered event source and a real MCP endpoint. |
| `SDK-OBSERVABILITY-FEEDS-R001.5` | **Event adapter entry points.** The SDK distribution registers its RUM, security-audit and CI/CD event bindings under their feed-kind names in the source-adapter group. Loading still requires an activation policy for the exact extension identity. Runner construction and a served connector run remain R001.4. | `tests/test_event_feed_registration.py::test_event_feed_entrypoints_require_certified_identity` |
| `SDK-OBSERVABILITY-FEEDS-R001.7` | **Optional event tenant binding.** When the host supplies an expected tenant, verify each event envelope before identity deduplication. A mismatch refuses the page before sink submission. The host must supply a trusted tenant; omitting the binding does not establish isolation. | `tests/test_event_feeds.py::test_bound_tenant_refuses_before_duplicate_classification` and `test_bound_tenant_refusal_preserves_sink_checkpoint`. |
