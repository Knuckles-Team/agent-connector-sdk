## Negative and boundary cases

A negative or zero interval clamps to zero and never sleeps (`test_interval_is_clamped_and_zero_never_waits`). A row that names a missing module path fails its index test. A row that names an unknown owner ID fails its index test. An extra in `pyproject.toml` that no row names fails `test_every_extra_has_a_row`.

## Quality and release proof

| CC-49 | `SDK-CENTRALIZED-CAPABILITIES-R004.1` | Unit | Feed unsafe first and next URLs to both iterators. | Refuse before fetching the unsafe URL. Errors contain no supplied credentials. |

| CC-50 | `SDK-CENTRALIZED-CAPABILITIES-R004.2` | Unit | Follow safe and unsafe Link headers with both iterators. | Cross-origin and credential-bearing links never reach the fetch callable. A repeated link ends the sweep. |

Run `uv run pytest tests/test_centralized_capability_index.py tests/test_centralized_extras.py tests/httpsupport/test_rate_limiter.py tests/httpsupport/test_pagination_next_url.py`. Run the `spec-standard` and `spec-status` hooks on the directory. A fleet-wide scan of connectors is outside this spec.

## Linear Link parsing (R004.3)

Compare generated and edge-case headers with the prior expression. Feed large
malformed headers through the iterator and confirm it ends after one fetch.

## Partial-page cursor safety (R004.5)

Run sync and async iterators with a page larger than the remaining budget.
They return no next cursor. A budget that ends on a full page keeps its cursor.

## Pagination consumer isolation (R004.7)

Interleave two consumers of one sync or async iterator. The second refuses
without resetting the first. Close or exhaust the first, then reuse it.
Also exercise claim release when a fetch fails.
