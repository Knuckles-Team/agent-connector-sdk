# SCION-SOURCE-INGEST requirements

| ID | Requirement | Verification |
|---|---|---|
| `SCION-SOURCE-INGEST-R001` | **Runner runs independent stages concurrently and resumes each from its receipt (rollup).** Subsystem: runner. Caller: `connector-sync --once` → `scion_sdk/runner/cli.py::main` → `scion_sdk/runner/worker.py::ConnectorWorker.run_once` → `ConnectorWorker._cycle` → `ConnectorWorker._sync` → `scion_sdk/runner/syncing.py::sync_stream`. The runner tracks progress only through the `SourceCheckpoint`. It builds its configuration from one root, `ConnectorDescriptor` in `scion_sdk/runner/descriptors.py`. Children: `.1` stage model in `scion_sdk/runner/stages.py` (present), `.2` behavior, `.3` wiring, `.4` refusal, `.5` evidence, `.6` hot path. Medulla owner of durable acceptance: MEDULLA-REPO-INGEST-R002. Depends on: none. | Root L4 journey: `tests/test_source_stages_served.py::test_concurrent_stage_restart`. |
| `SCION-SOURCE-INGEST-R002` | **SDK drift classifier handles incompatible schema changes.** The SDK's drift classifier deterministically compares prior and current schema digests. It emits a SchemaDriftReport classifying each change as compatible, needing review, or breaking. Incompatible pages are quarantined without advancing the SourceCheckpoint, per a declared schema evolution policy. MEDULLA-TYPED-PACKS-R083 provides the drift gate and the SHACL rendering that the runner calls. | Contract tests feed representative schema changes through the classifier and assert the correct SchemaDriftReport classification and quarantine behavior. |
| `SCION-SOURCE-INGEST-R003` | **SDK records and pauses on proposed schema repairs.** When a schema repair mapping is proposed, the connector SDK records the proposal and pauses the affected stream. It never builds a candidate graph schema, validates instances, performs a shadow ingest, or activates a repair itself. Those steps belong to the graph service. | Integration tests assert that a proposed repair pauses the stream and that the SDK makes no direct schema-activation call. |
| `SCION-SOURCE-INGEST-R004` | **Runner performs enterprise source synchronization.** Subsystem: runner and adapters. Caller: `connector-sync --once` → `scion_sdk/runner/cli.py::main` → `scion_sdk/runner/worker.py::ConnectorWorker.run_once` → `ConnectorWorker._cycle` → `ConnectorWorker._sync` → `scion_sdk/runner/syncing.py::sync_stream`. The runner performs full, delta and reconcile sync through the `SourceIngest` client and the presets the server declares. Connection profiling and data preparation stay in the SDK; medulla owns query meaning (MEDULLA-FEDERATED-QUERY-R085). Children `.7` to `.12` cover approved SQL execution. Children `.13` to `.18` cover the repository delta index. Children `.19` to `.53` keep their own rows. Children `.1` to `.6` are retired into `.7` to `.12`. | Root L4 journey: `tests/test_sync_modes_served.py::test_full_delta_reconcile_receipt_parity` runs the three sync paths against the real engine and compares receipts. |
| `SCION-SOURCE-INGEST-R005` | **SDK adapters cover document, conversation and feed sources (rollup).** Subsystem: adapters. Caller: `connector-sync --once` → `scion_sdk/runner/cli.py::main` → `ConnectorWorker._sync` (`scion_sdk/runner/worker.py`) → `sync_stream` (`scion_sdk/runner/syncing.py`) → `McpToolSourceAdapter.extract` (`scion_sdk/adapters/mcp_tool.py`). The SDK provides typed adapters for web fetch, package-install ingestion, repository transport and non-model readers. A connector registers each reader through `register_tool_surface`; the SDK holds no provider API. Children in this group are listed by topic. Paper providers: `.2` to `.6`. Offline bookmarks: `.9` to `.12`. Chain logs: `.14` to `.18`. Workspace formats: `.21`, `.24`. Scheduled intake: `.25` to `.30`. Citation facts: `.31` to `.36`. Web-source contract: `.40`. Medulla owners: MEDULLA-MEDIA-VOCAB-R002.5 (paper facts), MEDULLA-DECISION-ENGINE-R031.100 (paper admission). Connector callers: CONN-SCHOLARX-CONNECTOR-CONTENT-R002 to CONN-SYSTEMS-MANAGER-CONNECTOR-CONTENT-R004. | Root L4 journey: `tests/test_adapter_parity_served.py::test_each_source_type_produces_typed_envelopes_and_checkpoint` runs each registered reader through the real engine. |
| `SCION-SOURCE-INGEST-R005.1` | **Model.** Frozen `PaperQuery` carries tenant, query, provider IDs, continuation map, page bound and deadline. `PaperRecord` carries canonical ID, revision, title, authors, abstract, publication date, document offers and field provenance. `ProviderReport` carries provider, continuation token, outcome and reason. Outcomes are `ok`, `failed`, `rate_limited` or `refused`. `PaperSearchResult` contains records, reports and completeness (`complete`, `partial`, `failed`). `DocumentReceipt` binds tenant, paper ID, revision, source URL, media type, byte count, SHA-256 and local artifact reference. | SI-09 validates closed fields and malformed identity or limits. |
| `SCION-SOURCE-INGEST-R005.2` | **Paper providers: search, merge, quota and complete download.** Subsystem: adapters. Caller: connector `tools/call` → `scion_sdk/adapters/paper_tool.py::register_paper_search_tool` handler → `scion_sdk/adapters/paper_search.py::PaperSearchService.search`; documents through `register_paper_download_tool` → `paper_download.py`. Rule: query every configured provider in parallel within bounds. Merge on exact canonical identity (`paper_merge.py`): DOI lower-cased without URI prefix plus revision, or the provider and its record id. Never merge on title alone. A failed provider appears in `reports`; healthy results stay. Quota gates are shared for search, retry and download (`paper_quota.py`). Downloads stream to a temporary file under the tenant storage root. The SDK checks SHA-256 and length, then installs the file atomically under a digest name. Fill only missing metadata from the document, with parser identity and location. Config (constructor arguments, bounds in brackets): `max_providers` 8 [1, 32]; `page_bound` 100 [1, 1000]; `deadline_seconds` 60 [1, 600]. Also `read_retries` 2 [0, 5]; `max_document_bytes` 52428800 [1048576, 1073741824]; `transfer_deadline_seconds` 30 [1, 600]. Writes: local artifact files only; graph writes belong to R005.6 ingestion. Depends on: none. | Test: `tests/test_paper_contract.py::test_dedup_partial_failure_quota_download_and_metadata_fallback` (L2). Confirmed by the root slice test `tests/test_paper_source_served.py::test_served_search_download_and_sync` (L4). |

| `SCION-SOURCE-INGEST-R005.4` | **Paper refusals.** Subsystem: adapters. Caller: paper tool handlers (R005.3). | `SCION-SOURCE-INGEST-R005.5` | **Paper evidence and redaction.** Subsystem: adapters. Depends on: R005.2. | Test: `tests/test_paper_contract.py::test_provenance_conflicts_redaction_and_identity_stable_across_retries` (L2) checks every evidence field. |
