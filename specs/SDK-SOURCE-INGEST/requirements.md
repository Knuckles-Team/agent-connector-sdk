# SDK-SOURCE-INGEST requirements

| ID | Requirement | Verification |
|---|---|---|
| `SDK-SOURCE-INGEST-R001` | **SDK runner completes on generated ConnectorPack and SourceIngest contracts.** The connector SDK's runner implementation replaces placeholder sink and progress-tracking stubs with the generated ConnectorPack and SourceIngest contracts, tracks progress through SourceCheckpoint, and composes connector configuration from one root structure. | Integration tests run the runner against the generated SourceIngest client and confirm SourceCheckpoint state matches the contract after each page. |
| `SDK-SOURCE-INGEST-R002` | **SDK drift classifier quarantines incompatible schema changes.** The SDK's drift classifier deterministically compares prior and current schema digests and emits a SchemaDriftReport classifying each change as compatible, needing review, or breaking. Incompatible pages are quarantined without advancing the SourceCheckpoint, per a declared schema evolution policy. | Contract tests feed representative schema changes through the classifier and assert the correct SchemaDriftReport classification and quarantine behavior. |
| `SDK-SOURCE-INGEST-R003` | **SDK records and pauses on proposed schema repairs.** When a schema repair mapping is proposed, the connector SDK records the proposal and pauses the affected stream. It never constructs a candidate graph schema, validates instances, performs a shadow ingest, or activates a repair itself; those steps belong to the graph service. | Integration tests assert that a proposed repair pauses the stream and that the SDK makes no direct schema-activation call. |
| `SDK-SOURCE-INGEST-R004` | **SDK runner performs enterprise source synchronization.** The connector SDK's runner performs enterprise source synchronization through the generated SourceIngest client and manifest presets, and owns connection profiling and data-preparation for enterprise sources that agent-utilities no longer implements directly. | Integration tests exercise full, delta, and reconcile enterprise sync paths through the SDK runner and confirm receipt parity. |
| `SDK-SOURCE-INGEST-R005` | **SDK adapters cover document, conversation, and feed sources.** The connector SDK provides typed source adapters for document, conversation, and feed sources, including web fetch, package-install ingestion, repository-related transport, and non-model readers, replacing the equivalent agent-utilities implementations. | Adapter parity tests confirm each source type produces typed envelopes and a recoverable SourceCheckpoint through the generated SourceIngest client. |
| `SDK-SOURCE-INGEST-R006` | **SDK packs own vendor enrichment extraction and write-back.** Vendor enrichment extractors become SDK manifest presets and adapters, and write-back transport moves behind an SDK write-back module that calls the graph service's governed write-back contract. Repository history and source-adapter enrichment move into the SDK's repository adapter. | Adapter tests confirm each vendor extractor runs as an SDK preset and that write-back calls route through the governed contract. |
