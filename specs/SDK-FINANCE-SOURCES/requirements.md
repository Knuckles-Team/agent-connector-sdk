# SDK-FINANCE-SOURCES requirements

| ID | Requirement | Verification |
|---|---|---|
| `SDK-FINANCE-SOURCES-R001` | **Market-data adapters: exchange history fix, CoinMarketCap, FRED/ALFRED.** Market-data source adapters correct historical price retrieval for the exchange market-data connector, add CoinMarketCap market data, and add Federal Reserve FRED/ALFRED series with a central-bank announcement calendar, each preserving data vintage and announcement time per the shared adapter contract. | Offline conformance tests using recorded or synthetic responses for each adapter verifying corrected history retrieval and vintage and announcement-time fields. |
| `SDK-FINANCE-SOURCES-R001.1` | **Finite FRED values.** FRED normalization and direct macro-observation construction reject non-finite values instead of emitting invalid financial observations. | `tests/test_finance_fred_series.py::test_nonfinite_values_are_rejected` covers NaN, infinity, and overflow through both paths. |
| `SDK-FINANCE-SOURCES-R001.2` | **Cross-provider conformance.** Verify exchange history, CoinMarketCap, FRED/ALFRED vintage and central-bank announcement times through their real source adapters under the shared contract. | Offline source-adapter conformance tests cover each provider and required fields. |
| `SDK-FINANCE-SOURCES-R001.3` | **Refuse same-page calendar identity collisions.** If distinct announcement times map to one legacy event identity, refuse the page rather than return conflicting records. Equivalent timestamps for the same instant do not conflict. Existing IDs stay unchanged. | `tests/test_finance_central_bank_calendar.py` covers collision refusal and equivalent offsets. |
| `SDK-FINANCE-SOURCES-R001.4` | **FRED page shape.** FRED normalization rejects a missing or malformed observations array while accepting an explicit empty array. | `tests/test_finance_fred_series.py::test_observation_page_requires_an_array` covers invalid and empty pages. |
| `SDK-FINANCE-SOURCES-R001.5` | **Canonical FRED identity dates.** Observation and vintage dates use canonical calendar-date text. Alternate or malformed forms refuse before the event ID is built. | `tests/test_finance_fred_series.py` covers refusal and stable IDs. |
| `SDK-FINANCE-SOURCES-R001.6` | **Unique FRED page identities.** Refuse a page that repeats an observation period and vintage identity. Distinct vintages remain distinct records. | `tests/test_finance_fred_series.py` covers repeated IDs with equal and differing values. |
| `SDK-FINANCE-SOURCES-R002` | **Alpaca stocks adapter: history, quotes, fundamentals, calendars.** The Alpaca stocks source adapter supports historical bars, quotes, and streaming data with bounded pagination and explicit adjusted-versus-unadjusted and regular/pre/post-market handling, plus profile and fundamentals data, a licensed logo source, news, and an earnings and dividend calendar. | Offline conformance tests against recorded Alpaca fixtures covering pagination, adjustment mode, extended-hours flags, and each additional data type. |
| `SDK-FINANCE-SOURCES-R002.1` | **Complete Alpaca source coverage.** The source adapter supports bounded history, quotes, streaming and fundamentals. It also provides licensed logos, news, earnings and dividend calendars. It handles regular and extended hours explicitly. | Offline source-adapter conformance fixtures cover all required data types, pagination, session handling and adjustment modes. |
| `SDK-FINANCE-SOURCES-R002.2` | **Finite market records.** Bars, quotes and corporate actions reject non-finite numeric values. | `tests/test_finance_records.py::test_market_records_reject_nonfinite_values` covers each numeric field. |
| `SDK-FINANCE-SOURCES-R002.3` | **Alpaca page shape.** Bar normalization requires a valid bars array, the requested symbol and an explicit pagination token. It rejects malformed pages rather than assuming completion. | `tests/test_finance_alpaca_stocks.py::test_malformed_page_is_rejected` and `test_explicit_empty_page_is_valid` cover refusal and empty data. |
| `SDK-FINANCE-SOURCES-R003` | **FX, commodities, and real-estate adapters with roll and staleness rules.** FX source adapters identify base and quote currency and rate direction. Gold and commodities adapters distinguish spot price from a specific futures contract, its expiry, and an explicit roll rule. Real-estate adapters return a dated, potentially stale valuation rather than a live market quote. | Offline conformance tests per asset class asserting correct base/quote identity, spot-versus-futures roll handling, and valuation staleness reporting. |
| `SDK-FINANCE-SOURCES-R003.1` | **Multi-asset source adapters.** Provide and verify FX, commodity and real-estate source adapters. Preserve rate direction, futures roll rules and dated valuation staleness. | Offline conformance fixtures exercise each source adapter and its required asset semantics. |
| `SDK-FINANCE-SOURCES-R003.2` | **Finite multi-asset prices.** FX rates and commodity prices refuse non-finite values; FX inversion refuses overflow instead of returning a non-finite rate. | `tests/test_finance_records.py` covers invalid values and inversion overflow. |
| `SDK-FINANCE-SOURCES-R003.3` | **Canonical FX currency identity.** FX base and quote codes use three ASCII letters in uppercase. The model refuses a pair with identical codes. | `tests/test_finance_records.py` covers normalization, distinctness and malformed codes. |
| `SDK-FINANCE-SOURCES-R004` | **Alpaca account reads and idempotent CSV activity import.** Account import reads Alpaca account and position data and imports CSV activity statements with a column-mapping preview, rejecting ambiguous columns or currencies, and identifies each activity row by a stable provider event ID or source-file digest plus row identity so re-import is idempotent. | Conformance tests that re-import the same CSV file and Alpaca account snapshot and assert no duplicate activity record is created. |
| `SDK-FINANCE-SOURCES-R004.1` | **Account source and durable re-import.** Verify Alpaca account and position reads through their source adapter. Re-import the same snapshot and CSV into the sink without duplicate activity. | Conformance tests exercise the source and sink together and assert durable activity identity. |
| `SDK-FINANCE-SOURCES-R004.2` | **Finite account values.** Snapshots, positions and activities reject non-finite numeric fields. | `tests/test_finance_account_read.py` and `tests/test_finance_csv_import.py` exercise account and CSV normalization. |
| `SDK-FINANCE-SOURCES-R004.3` | **Reject duplicate CSV headers.** Preview and import refuse repeated header names before parsing activity rows. | `tests/test_finance_csv_import.py::test_duplicate_headers_are_rejected` covers mapped and unmapped duplicates. |
| `SDK-FINANCE-SOURCES-R004.4` | **Reject ragged CSV rows.** Preview and import reject rows with more or fewer cells than their header. | `tests/test_finance_csv_import.py::test_ragged_rows_are_rejected` covers both mismatches. |
| `SDK-FINANCE-SOURCES-R004.5` | **ASCII currency syntax.** CSV currency codes use three uppercase ASCII letters; Unicode lookalikes are refused. This does not prove ISO registry membership. | `tests/test_finance_csv_import.py::test_non_ascii_currency_is_rejected` covers lookalikes before import. |
| `SDK-FINANCE-SOURCES-R004.6` | **Redact invalid currency cells.** CSV preview and import refuse malformed currency values without including cell contents in errors. | `tests/test_finance_csv_import.py::test_preview_rejects_an_unrecognized_currency_code` asserts both paths. |
| `SDK-FINANCE-SOURCES-R005` | **Macro and liquidity panels: FRED series, ETF flows, sentiment, on-chain.** Macro and liquidity source adapters provide Federal Reserve FRED series with preserved vintage, a versioned liquidity composite and heat-strip panel, ETF fund-flow data, sentiment data, and on-chain position data, each tagged with its source and observation time. | Offline conformance tests against recorded or synthetic fixtures for each panel type asserting vintage preservation and correct source provenance tagging. |
| `SDK-FINANCE-SOURCES-R005.1` | **Complete macro panel sources.** Verify FRED and ETF flows through real source adapters. Verify the versioned liquidity composite and heat strip. Verify sentiment and on-chain positions with source and observation time. | Offline conformance fixtures cover each required panel type and its provenance. |
| `SDK-FINANCE-SOURCES-R005.3` | **ETF page shape.** ETF normalization rejects a missing or malformed flows array while accepting an explicit empty array. | `tests/test_finance_etf_flows.py::test_flow_page_requires_an_array` covers invalid and empty pages. |
| `SDK-FINANCE-SOURCES-R005.2` | **Finite ETF values.** ETF flow normalization and direct model construction reject non-finite net flow and assets under management. | `tests/test_finance_etf_flows.py::test_nonfinite_amounts_are_rejected` covers both fields through both paths. |
| `SDK-FINANCE-SOURCES-R900` | **Venue and API connector helpers (rollup).** The SDK provides venue and API helpers only. `finance.market_data` chains market-data providers. `finance.crypto` reads DEX volume, TVL and funding rates. `finance.feeds` builds live bars on `streaming.StreamBus`. `payments` runs the HTTP 402 payment flow. `finance.strategy_export` renders strategy source. `finance.banking` builds ISO 20022 messages. The graph service owns finance calculations and decisions (`EG-FINANCE-PRIMITIVES-R900`, `EG-FINANCE-PRIMITIVES-R901`). The `market` and `stream` extras provide the provider and WebSocket clients. Children `.1` through `.6` cover model, behavior, wiring, refusal, evidence and hot-path proof. | See each child. |
| `SDK-FINANCE-SOURCES-R900.1` | **Model.** `DataRegistry`, `OnChainAnalytics`, `CryptoDerivatives`, `MarketFeedBus`, `StreamBus`, `X402PaymentClient`, `StrategyExporter` and `ISO20022MessageFactory` are the public surface. | `tests/test_finance_strategy_export.py::test_exporter_dispatches_by_platform_and_exports_all` |
| `SDK-FINANCE-SOURCES-R900.2` | **Behavior.** The registry returns the first non-empty provider result and never fabricates data. A price alert fires once when its threshold is crossed. | `tests/test_finance_market_data.py::test_first_non_empty_provider_wins_and_failures_become_warnings` |
| `SDK-FINANCE-SOURCES-R900.3` | **Wiring.** Crypto reads use `agent_connector_sdk.source_connectors.http_safety`. Feeds publish through `agent_connector_sdk.streaming`. | `tests/test_finance_feeds.py::test_ticks_fan_out_by_symbol` |
| `SDK-FINANCE-SOURCES-R900.4` | **Refusal.** A malformed upstream answer raises `ProviderRequestError`. The payment guard refuses a payment outside any budget, currency or chain limit. | `tests/test_payments.py::test_guard_approves_only_within_every_limit` |
| `SDK-FINANCE-SOURCES-R900.5` | **Evidence.** Tests inject fetch callables and in-memory providers. They use no network and no sleep. | `tests/test_finance_crypto.py::test_malformed_answers_raise_provider_request_error` |
| `SDK-FINANCE-SOURCES-R900.6` | **Hot-path proof.** The entry point is `X402PaymentClient`. The proof parses a 402 challenge, makes a proof, records the payment and verifies the remaining budget. | `tests/test_payments.py::test_client_parses_402_proves_and_records_spend` |
| `SDK-FINANCE-SOURCES-R900.8` | **Bind confirmed payment records to proofs.** A confirmed record requires a proof whose challenge, amount, currency, chain, recipient and sender match the challenge and configured wallet. Refusal changes neither the record history nor spend counters. The SDK does not verify the underlying transaction. | `tests/test_payments.py::test_confirmed_payment_rejects_mismatched_proof_without_accounting` tests each mismatch and missing proof. |
| `SDK-FINANCE-SOURCES-R900.7` | **Independent market bar intervals.** A symbol supports multiple bar intervals. Each interval aggregates every matching tick and publishes to its own topic. Repeated subscriptions to one interval share one aggregator. | `tests/test_finance_feeds.py::test_bar_subscriptions_use_independent_intervals` subscribes to two intervals and asserts each completed bar. |

| `SDK-FINANCE-SOURCES-R900.9` | **Positive bar intervals.** The feed and tick aggregator refuse non-positive or non-integer bar intervals. A refused subscription adds no subscriber. | `tests/test_finance_feeds.py` covers both entry points and refusal without side effects. |
| `SDK-FINANCE-SOURCES-R900.10` | **Finite live ticks.** The market bus and direct bar aggregation reject non-finite tick values and alert thresholds. Invalid ticks cause no publication or aggregation. | `tests/test_finance_feeds.py` tests invalid and mutated ticks at each entry point. |


| `SDK-FINANCE-SOURCES-R900.11` | **Funding source time.** Funding-rate reads require a finite rate and explicit finite provider timestamp. Missing or malformed values refuse rather than substituting local time. | `tests/test_finance_crypto.py` covers invalid values and preserves the provider timestamp. |

| `SDK-FINANCE-SOURCES-R001.7` | **Bounded exchange history windows.** CryptoProvider requests the selected period and interval, then reads advancing CCXT pages. It rejects unsupported windows, malformed bars, repeated timestamps and a page-cap overflow instead of returning a partial result. | `tests/test_exchange_history_window.py` exercises the real provider with an offline exchange. |
