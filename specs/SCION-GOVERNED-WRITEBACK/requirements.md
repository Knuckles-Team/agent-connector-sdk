| `SCION-GOVERNED-WRITEBACK-R001` | **Write-back proposals route through governed authorization (rollup).** A proposed change to an attached source is evaluated only through the governed write-back protocol's deterministic authorization modes. A decision-service suggestion is never an approval. It cannot authorize applying the change. `scion_sdk/decide/consumers.py::propose_writeback` returns a proposal and defaults to `NO_WRITE`. Children `.1` to `.6` deliver wallet-signature proof as an independent verification inside `GovernedWriteBack.apply`. Consumer: ARBORA-DATA-MARKET-R007. Engine owner of authorization: MEDULLA-UNIFIED-DATA-PLANE-R012. | Test: `tests/test_decide_consumers.py::test_writeback_is_only_ever_a_proposal` (L2) asserts refusal without a separate approval record. Served proof: `tests/test_wallet_proof_served.py::test_served_wallet_proof_and_governed_apply` (L3) from `.6`. |
| `SCION-GOVERNED-WRITEBACK-R001.1` | **Model.** Stage: wallet operation prepare. Code: new `scion_sdk/writeback/wallet_intent.py`. The closed models `WalletProofRequest`, `WalletProofBinding`, `WalletKeyTrust` and `WalletProofResult` already exist in `scion_sdk/writeback/wallet_proof.py`. Add `WalletBusinessIntent` with `operation_id`, `account_id`, `wallet_id`, `network_id`, `key_id` and `params`, a canonical JSON object of at most 16384 bytes. Add `WalletConfirmation` with `confirmed_by`, `confirmed_at_ms` and `plan_digest`. Add `WalletExecutionEnvelope` with `intent`, `confirmation` and `proof`, where `proof` is `WalletProofRequest` or none. Add `wallet_plan_digest(intent)`: the SHA-256 of RFC 8785 canonical JSON of `{"intent": intent}`, as 64 lowercase hex characters. Intent never contains the proof or the plan digest. Models forbid extra fields and are frozen. A verification result is a fact and never an authorization grant. Refusals: `ValidationError` for unknown fields, a digest that is not 64 lowercase hex characters or an oversized `params`. Writes: none. Depends on: none. | Test: `tests/test_wallet_proof_contract.py::test_intent_and_envelope_models_are_closed` (L1) round-trips both models and rejects each invalid shape. | `SCION-GOVERNED-WRITEBACK-R001.2` | **Behavior.** Stage: wallet operation verify.
